# 万哥牛逼双语 README 设计

## 目标

更新仓库根目录 `README.md`，用中英文对照方式准确介绍 Skill 的用途、执行边界、预计耗时和真实输出。移除已经过时的“44 个公开仓库”说明，避免 README 与当前脚本行为不一致。

## 内容结构

README 按以下顺序组织：

1. 标题与中英文简介。
2. `执行耗时 / Execution Time`：同时给出常见路径预期区间、真实测量值和影响耗时的条件。
3. `真实输出 / Real Output`：记录带日期和运行条件的真实 Dry Run 快照。
4. 两个折叠区：完整中文原始输出、基于同一快照的完整英文翻译。
5. `使用边界 / Boundaries`：中英文逐条对应。
6. 指向 `SKILL.md` 的实现与故障处理链接。

## 耗时口径

- 常见路径预计耗时写为 `2–4 秒`。
- 实测速据固定记录为：2026-08-17、Windows、PowerShell 7、Dry Run、2.68 秒、37 个公开仓库、1 次 GraphQL API 调用、0 次 PUT。
- 明确说明该区间不是性能承诺；网络延迟、GitHub API 重试、分页以及实际需要补 Star 的仓库数量都会增加耗时。
- 不把当前 Stars 或仓库数量表述为永久事实；它们属于带日期的实测快照。

## 输出演示

- 中文折叠区逐字保留脚本真实生成的 Markdown，包括摘要、37 个项目的完整总榜、作者概览和私有仓库边界。
- 英文折叠区完整翻译同一份快照，保持仓库顺序、Stars、状态和统计数字不变。
- 英文翻译明确标注为 `English rendering of the same snapshot`，避免让读者误以为脚本当前会直接生成英文。
- 总榜中的仓库链接继续指向真实 GitHub 项目。
